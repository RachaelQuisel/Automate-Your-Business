## Part one: recall before acting

Read the short memory first, before the job starts. Read only the cards for this job, this house, this customer, or this kind of work.

1. Find the cards for this job. Time spent reading: ______________ minutes.
2. Read each card that fits what you are about to do.
3. Follow the check on the matching card first.
4. Mark what you found: Circle one: The memory covers this job / The memory is silent on this job / A card exists but it looks stale

What "silent" means: no card covers what you are seeing.
What "stale" means: a card exists, but the job, the house, or the system has changed since it was written, or its source is too weak to trust for this decision.

## Part two: act

Do the job.

- If the memory covers the job and it still fits, do the job using the card. Do not repeat the full investigation out of habit.
- If the memory is silent or stale, dig deeper: look, test, call, and check the original source. Write down what you checked while you work, so the write back step is easy.

## Part three: write back after, with the card template

Before the job counts as finished, ask: what did this job teach us that the memory did not already say?

- If there is a lesson, write one small card for that one lesson. One lesson per card.
- If there is no durable lesson, write this one line and stop: "Nothing durable today." Date: ______________  Job: ______________________________

The card template. Copy this shape for every new card.

| Field | What to write |
|---|---|
| What happened (the symptom) | What a person saw, heard, or was told, in plain words, without guessing the reason yet |
| Why (the cause) | The reason, only as far as it was actually confirmed. If it was not confirmed, write "not confirmed" here |
| How to check | The short check the next person should do first. One to three steps, in order |
| The fix | What solved it this time, or what to do when the check shows the same pattern again |
| Source named | Who or what this came from, with a date where you have one. A person, an invoice, a message, a reading, a photo |
| Gaps marked "not confirmed" | Every part you did not check, written with the exact words "not confirmed". Do not guess to make the card look finished |

Worked example, from a home services and rental care business:

- What happened: The kitchen lost power when the microwave and the kettle ran at the same time.
- Why: Both appliances share one circuit, confirmed by the electrician on site.
- How to check: Check breaker six in the hall panel before calling an electrician.
- The fix: Move the kettle to the dining room outlet and leave a note by the microwave.
- Source named: Electrician visit, invoice and date named on the card.
- Gaps marked "not confirmed": Not confirmed whether the toaster on the same counter causes the same trip.

## Part four: the durability test and the review

### The durability test checklist

A card must pass all three questions. If it fails any one question, do not file it. Write "Nothing durable today" instead.

For each card, circle Yes or No:

1. Is it not obvious at a glance? Yes / No
   If anyone walking in would see it in ten seconds, it does not need a card.
2. Will it still be true next month? Yes / No
   A one day delay or a temporary preference will not pass. A layout, a machine quirk, or a vendor habit that repeats will pass.
3. Would it have saved time today? Yes / No
   If having this card at the start of today's job would not have changed anything, it is trivia, however interesting it is.

Result for this card: Circle one: Passes all three, ready for review / Fails one or more, not filed

### The review checklist

A person reads each new card before it becomes the way the business does things. Until the review happens, label the card as a draft.

The reviewer checks each item and ticks it when it is true:

- [ ] The symptom matches what actually happened.
- [ ] The cause is stated only as far as it was confirmed.
- [ ] Every unconfirmed part is marked "not confirmed", with no guesses filling the gaps.
- [ ] The source is named, and another person could find it from what is written.
- [ ] The check is short, in order, and safe for the next person to do first.
- [ ] The fix is clear enough for the next person to follow without asking the writer.
- [ ] The card passes all three durability questions.

Review result: Circle one: Approved as written / Approved after a small wording fix / Sent back
