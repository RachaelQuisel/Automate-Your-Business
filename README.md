# Automate Your Business

Automate Your Business is a free, hands-on workshop for small business owners and the people who run their operations. Each session takes one task you do by hand and turns it into a working system. You leave with a filled-in worksheet and a next step you can take that week.

Rachael Quisel teaches it. Rachael is an AI and Automation Workflow Consultant at [XRAY](https://xray.tech). Her portfolio is at [github.com/RachaelQuisel](https://github.com/RachaelQuisel).

## What is in each folder

| Folder | What it holds |
| --- | --- |
| `workshops/` | One folder per workshop. Each folder has `workshop.md` (the plan) and `handout.md` (the worksheet). |
| `sources/snips/` | The podcast highlights each workshop is built from, copied word for word, with a link to each one. |
| `content-ideas/` | Drafts for social posts, such as the Series of Loops carousel. |
| `templates/` | The structure every workshop follows. |
| `state/processed-episodes.md` | The list of podcast episodes already turned into workshops, so none is used twice. |
| `CLAUDE.md` | The instructions the automated writer follows each time it runs. |
| `PLAN.md` | The plan for improving how workshops get made. |

## How a new workshop gets made

1. Rachael listens to a podcast in the Snipd app and saves the moments worth keeping. Snipd calls these snips.
2. Snipd emails the snips to Rachael.
3. A scheduled Claude routine reads those emails. It picks one episode that has not been used yet.
4. The routine saves the snips in `sources/snips/`, writes a workshop plan and a handout from them, and adds both to this repository.
5. The routine posts the full workshop to the team's private Slack channel.

The routine runs in the cloud, so it cannot see local files. Anything edited by hand has to be pushed to GitHub before the next run.
