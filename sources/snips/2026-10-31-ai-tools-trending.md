### Snip 1: Make Claude interview you before it does multi-step work
- Source: The Neuron, daily digest
- Episode/article: "New York Sets Rules for AI Chatbots and Kids"
- Date: 2026-10-31
- Link: https://www.theneurondaily.com/p/new-york-curbs-ai-chatbots-for-kids
- Summary: The Neuron's AI Skill of the Day, from Ruben Hassid's How to AI newsletter, is a one-line change to how a big task starts in Claude Cowork, Anthropic's desktop app that works on files in a folder you choose. The line tells Claude to use its AskUserQuestion tool before answering, to gather enough context first. Instead of guessing, Claude pops up a clickable form with buttons and rankings, the person answers in a couple of minutes, Claude shows a plan, the person adjusts it, and only then does it build. Hassid pairs it with a small folder holding an about-me file and examples of past work, so Claude already knows his voice, and uses the loop for newsletter drafts, client briefs turned into Word documents, and competitor comparison tables. The Neuron gives a version that works in any chatbot: state the task and what success looks like, ask for every needed question in one batch, then require a short plan and a wait for approval before drafting. Two cautions are stated in the post: Cowork is a research preview that can misread files, and it reads and writes whatever folder you share, so keep that folder limited. This is today's workshop pick.
- Loop/workflow angle: a complete workflow in one habit. Interview first, plan second, approval third, draft fourth, and the guessing moves to the start of the job, where a wrong answer costs one click instead of a rewritten draft.

### Snip 2: Gemini now creates, previews, and edits files inside the chat
- Source: Unite.AI, reporting Google's October 29 announcement
- Episode/article: "Gemini App Now Lets Users Edit Documents and PDFs In-Chat"
- Date: 2026-10-29
- Link: https://www.unite.ai/gemini-app-now-lets-users-edit-documents-and-pdfs-in-chat/
- Summary: Google announced on October 29, 2026 that Gemini app users can now generate, preview, and edit documents, PDFs, presentations, spreadsheets, code, and other files directly within a chat, extending the file generation first introduced in April. A file created in a conversation no longer needs to leave the chat to be revised. There are three editing routes: expand the file to full screen and type edits directly, highlight text inside the file to ask questions about that passage, or direct Gemini itself to refine the file. Google's example turns uploaded handwritten lecture notes into a PDF study guide, which the user then edits by hand, highlights sections for Gemini to change, and asks follow-up questions about, all in one session. PDF preview and editing work on web and mobile; Google Docs, Sheets, slide decks, Markdown, plain text, and code are web only for now. Google says the update is available to all users in all languages where the Gemini app is available.
- Loop/workflow angle: this closes the loop Snip 1 opens. The interview produces a plan, the plan produces a file, and now the file is reviewed and fixed in the same room, by hand or by highlight, instead of being downloaded, opened elsewhere, and re-uploaded.

### Snip 3: Agent Skills moves to a vendor-neutral foundation under the Linux Foundation
- Source: Agentic Skills, analysis of the October 22 donation
- Episode/article: "Agent Skills Moves to the Linux Foundation What Changes for Your Skills, and What Doesn't"
- Date: 2026-10-22
- Link: https://agenticskills.io/learn/agent-skills-linux-foundation
- Summary: On October 22, 2026, Anthropic donated Agent Skills, the open standard behind the SKILL.md file format for teaching an agent a specific task, to the Agentic AI Foundation under the Linux Foundation, the same foundation project that already hosts MCP, the connection standard, and AGENTS.md. The donation covers the Agent Skills name and logo, the GitHub organization, and the agentskills.io domain. The format did not change: a skill is still a folder with a SKILL.md file, and the specification was last edited on August 4, 2026. Engineers from Anthropic, Google, OpenAI, and other companies maintain the standard as individuals, with David Soria Parra and Mahesh Murag as lead maintainers. Reporting on the donation puts the scale at more than 70 agent platforms using the format, one million published skills, and roughly 280 million installs. One practical warning in the analysis matters for anyone writing skills today: the standard allows six frontmatter fields, while Claude Code accepts twenty, and a skill using a field outside the six can break outside Claude Code or fail on upload elsewhere.
- Loop/workflow angle: procedures written once, in plain files a business owns, now have a neutral home, so changing assistants does not have to mean rewriting how the business works. The six-field limit is the portability check to run before a skill leaves home.

### Snip 5: New York sets rules in law for AI chatbots children can reach
- Source: The Neuron, daily digest
- Episode/article: "New York Sets Rules for AI Chatbots and Kids"
- Date: 2026-10-31
- Link: https://www.theneurondaily.com/p/new-york-curbs-ai-chatbots-for-kids
- Summary: New York Governor Kathy Hochul signed a law on October 28, 2026 that governs what a chatbot does, not only what a company discloses. For users under 18, companies cannot offer features where the bot pretends to be a real person, alive, or having human emotions, claims a personal, romantic, professional, or authority relationship with a child, asks unprompted emotional questions or reuses a child's private information from earlier conversations, promotes or helps with suicide, self-harm, eating disorders, or drug and alcohol use, encourages keeping secrets from trusted adults, or provides sexually explicit content. The limits apply to any user unless the company has confirmed the user is an adult, companies must offer more than one age-verification method with at least one not relying solely on government identification, and age data must be deleted after use. The attorney general can seek civil penalties of up to 25,000 dollars per violation, plus damages and destruction of unlawfully collected data or models trained on it, with model destruction a remedy the state can request rather than an automatic result. The Neuron notes a timing gap in the sources, with features to be blocked in the coming months and a January 1, 2027 start listed in its digest, so the date should be checked before planning around it.
- Loop/workflow angle: for any business whose helper can be reached by minors, this is a concrete audit list, not an abstract debate. Write the six banned behaviors into the helper's instructions, decide how an adult is confirmed, and keep the deletion rule for age data in the same policy page.

### Snip 8: Open-source agent tools give each agent its own room, a flight recorder, and a regression alarm
- Source: My2Cents, open-source agent tools roundup
- Episode/article: "Open Source Agent Tools: October 30, 2026"
- Date: 2026-10-30
- Link: https://www.my2cents.ai/news/2026-10-30-open-source-agents/
- Summary: The October 30 roundup of open-source agent tools posted to Show HN on October 29 covers six projects with one shared theme: separation and evidence. Wavefunction is a minimal desktop coding agent for the Mac that splits tasks across subagents the user can steer mid-task, gives subagents that could touch the same files their own separate work copy, and runs computer use inside its own container instead of on the user's screen. Cornercase turns an issue from a tracker into a coding agent working in its own work area and tab, with a live view of the changes and per-piece staging, discard, or send-back. Mnestiq is a flight recorder for agents that tags every piece of model context with where it came from, so a prompt-injection incident can be traced to the step and the untrusted input that preceded it, with records sealed so edits or deletions fail verification. Apgar watches the first hours after each agent release and compares it with the previous release on tool errors, retries, loops, cost, and latency, then sends one message naming the signal that moved. Charter enforces per-field rules on agent calls into customer accounts, and phpClaw brings a capped agent loop with prompt-injection guards to PHP.
- Loop/workflow angle: the open-source crowd is building the same safety shape as the big labs, in public. One room per agent so parallel work cannot collide, a recorder that proves what the agent read and did, and an alarm that fires when a new version behaves worse than the last one.

### Snip 9: Canva Craft plans the layout before it draws, because it was trained on designs, not photographs
- Source: eesel AI, review built from Canva's launch material
- Episode/article: "Canva Craft review: how Canva's first image model actually works"
- Date: 2026-10-22
- Link: https://www.eesel.ai/blog/canva-craft-review
- Summary: Canva Craft, launched October 22, 2026, is Canva's first image generation model built and trained from scratch by Canva Research, an in-house lab of more than 160 AI scientists and engineers. Its difference is the training set and the order of work. Craft was trained on millions of human-designed templates from Canva's library, posters, social posts, presentations, infographics, menus, and typography-heavy layouts, rather than primarily on photographs. Generation runs in two stages: a planning model first writes a composition plan covering what goes where, how big each element is, the visual hierarchy, and the exact text, and a rendering model then produces the image at up to 2K resolution. Craft debuted at number four on DesignArena, a crowdsourced comparison benchmark, behind three OpenAI models, ranking first for portraits and landscapes in Canva's published category figures and sixth for marketing materials. It is live for every Canva user in Dream Lab and for developers through the Connect API, and it spends from the plan's shared AI allowance, which the review notes is up to 20 uses on Free and Pro trial accounts, so a trial is a thin test. The review is built from Canva's own launch publications, not independent testing.
- Loop/workflow angle: plan first, render second is Snip 1's lesson inside an image model. A written composition plan a person could, in principle, read and fix before any pixels are spent is easier to trust and cheaper to correct than a finished image with the text already wrong.

### Workshop pick: Snip 1, Make Claude interview you before it does multi-step work
The richest end-to-end workflow in today's file is the interview-first loop, because it fixes the most expensive moment in every AI job, the first five minutes, when the helper guesses what you meant and builds the wrong thing beautifully. The workflow is complete and needs no special product. Write a short about-me file with your role, your customers, and how you sound. Keep one or two examples of your best finished work beside it. Start every big task with the same opening: here is the task, here is what success looks like, ask me every question you need in one batch before you write anything, then show me a short plan and wait for my approval. Answer the questions, fix the plan, and only then let it draft. The workshop is called Make Your AI Helper Interview You Before It Starts. It carries today's other stories with it: the file finished inside the same chat (Snip 2), the plan-before-rendering habit inside Canva Craft (Snip 9), and the Allow, Ask, or Block rule for what the helper may do without coming back to you (Snip 7).
